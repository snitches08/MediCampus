MediCampus — Stitch-inspired clickable prototype
================================================

Files
- MediCampusApp.py: Python/Tkinter prototype.

Run
1. Extract the ZIP.
2. Install Python 3 if needed.
3. Open a terminal in this folder and run:
   python MediCampusApp.py

Schedule screen improvements
- Select clinic category filters (All Campus Clinics, Main Student Infirmary, Sports).
- Select a date in the week strip.
- Choose an available time chip and proceed to booking.
- Open Map View and provider information pop-ups.
- Join the sample walk-in queue.
- Use the bottom navigation to move between Home, Schedules, Records, and Profile.
